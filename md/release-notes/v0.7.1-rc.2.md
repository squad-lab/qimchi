### v0.7.1-rc.2 - 2026-10-04

- [Feature] Settings > Updates shows the changelog for the version you are running, formatted and scrollable, even when you are offline.
- [Fix] Update prompts now show the offered version's release notes, instead of the installation instructions from the release page.
- [Fix] Choosing "Start Qimchi after installation" while updating on Windows now starts Qimchi. Before, it closed again straight away because it thought the update was still running.
- [Fix] Qimchi opens again by itself after an in-app update. Before, Windows Setup (and the Linux AppImage updater) started it, but it closed again at once without a window.
- [Misc] Windows setup has a fresh look and only two pages: choose the install folder, desktop shortcut and whether to start Qimchi, then install. Qimchi starts after installation if that option is selected.
- [Misc] The macOS disk image opens a branded window where you drag Qimchi to Applications, and both the app and the mounted disk show the Qimchi icon. The app is now called Qimchi.app, with a capital Q.
